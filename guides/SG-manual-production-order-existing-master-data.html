Production order

Draft 6 phases Updated 2026-09-02

Manufacturing · Warehousing

Objective: create a quantity-one manual production order from an existing finished item, existing components, an existing BOM, and an existing routing; verify the generated operations and estimated materials; release the order; issue material to the job shop; report the operation(s) complete; and confirm the finished item is received into the warehouse.

Scope note: this guide ends at finished-goods receipt. Close Production Orders ticst0201m000 — actual-cost calculation and financial posting — is out of scope and remains future work.

Use the finished-goods receipt as the boundary. This guide is complete only when Production Orders shows Order Status Completed with Quantity Delivered equal to the production quantity, and Inventory 360 confirms the receiving warehouse's on-hand increased by the same amount. Do not run Close Production Orders ticst0201m000 from this guide.

This phase reads the finished item, its component, the BOM and routing revisions, the warehouses and the stock before the order asks for them.

Phase 1 — Create the production order

Route
Manufacturing ➔ Job Shop ➔ Production Orders
Session
Production Orders tisfc0501m000

What LN is doing. On save LN reads the item's BOM and routing valid on the Reference Date and generates the order's operations and estimated materials from them. Quantity Ordered is what is to be produced and Warehouse is where the result will be received. The order exists at Created; nothing has moved.

Phase 2 — Verify the generated foundation

Route
Manufacturing ➔ Job Shop ➔ Production Orders
Session
Production Orders tisfc0501m000

What LN is doing. The detail session shows what LN generated at creation: the planning area holds the operations from the routing and the estimated-materials area holds the components from the BOM, scaled to the order quantity. A missing operation, BOM or component here is a stop condition, not something to repair inside the order.

Phase 3 — Release the order

Route
Manufacturing ➔ Job Shop ➔ Production Orders
Session
Production Orders tisfc0501m000

What LN is doing. Release changes the order to Released, the state in which production can start, and at the same moment LN creates two warehousing orders: one to issue the component out of its warehouse and one to receive the finished item into its own. Phase 4 works the first; phase 5 depends on the second.

#
Do this
You should see
3.1Select the production order row from step 1.8The row is highlighted
3.2Actions ➔ Release OrdersRelease Production Orders tisfc0204m000 opens
3.3Confirm the selection range narrows to this one production orderOnly this order is in scope for the release run
3.4Run the releaseThe dialog closes; back in Production Orders, order status after release = Released
3.5Confirm no other order changed statusOnly the order from step 1.8 shows Released

Phase 4 — Issue material to the job shop

What LN is doing. Material issue turns the estimated quantities into an outbound warehousing order from the raw-material warehouse to the work center, and each issued quantity books a WIP transaction. That first WIP transaction is what moves the order to Active; release alone does not. How much of the outbound procedure LN runs for you depends on two check boxes on the material line.

#
Do this
You should see
4.1Open Manufacturing ➔ Job Shop ➔ Production Materials ➔ Material to Issue for Production Orders (ticst0101m100) for the order released in phase 3The component line from step 0.1 is listed, with Production Order Status = Released
4.2Read Estimated Quantity, Actual Quantity, and To Issue by Warehouse for the component line material to issue = the To Issue by Warehouse figure; Actual Quantity = 0
4.3If the line is not already unblocked, run Initiate Inventory Issue tisfc0207m000 for the lineThe material's warehouse order line unblocks
4.4Open Warehousing Orders whinh2100m000 and find the production issue order for this production orderThe order shows order type 30- Production (Out), source the component warehouse from step 0.4, destination the work center from the routing
4.5Click Drill In on the issue order — Warehousing Order whinh2100m100The order lines and the Outbound Line Status Overview whinh2129m000 activity list are visible
4.6If Generate Outbound Advice and Release Outbound Advice show unfinished and not automatic, run themThe advice is generated and released
4.7Continue the outbound procedure until the issue order reaches ShippedOrdered and advised quantities match; the order shows Shipped
4.8Return to Material to Issue for Production Orders and Production OrdersActual Quantity = the estimated quantity, To Issue by Warehouse = 0; order status after material issue = Active

Phase 5 — Report the operation complete and confirm warehouse receipt

Route
Manufacturing ➔ Job Shop ➔ Production Control ➔ Report Operations
Session
Report Operations tisfc0130m000

What LN is doing. Reporting the last operation complete records the quantity produced and, depending on a parameter, posts it to inventory silently, not at all, or after asking. The order becomes Production Completed when reported and Completed only when Warehousing finishes the inbound receipt, so the two statuses are a handoff, not a failure. The phase ends with an inventory read because the Manufacturing-side status alone does not prove the stock arrived.

#
Do this
You should see
5.1Open Manufacturing ➔ Job Shop ➔ Production Control ➔ Report Operations (tisfc0130m000) for the order's next operationThe operation line shows Operation Status, Planned Output, and the item from step 0.1
5.2Enter the production quantity from step 1.4 in CompletedThe quantity is accepted
5.3SaveIf this was the last operation, LN can book the completed product into inventory
5.4Repeat steps 5.1–5.3 for each remaining operation, in routing sequenceEach operation reports complete in turn
5.5On the last operation's save, if Report Orders Completed tisfc0120s000 opens, enter the completed quantity in Additional Quantity to Deliver and saveLN asks "Automatically confirm receipt when activating warehouse order inbound line?" — see the note below before answering
5.6Answer the receipt question, and record which way you answered receipt answer; delivered = the production quantity if you answered Yes
5.7Return to Production Orders tisfc0501m000 and read Order Status order status after reporting. Production Completed means Warehousing has not finished the inbound procedure yet; Completed means the goods are in inventory. On the Yes path expect Quantity Delivered = the production quantity and Quantity to Deliver = 0; on the No path the quantity sits in Quantity to Deliver until Warehousing processes the inbound line
5.8Open Inventory 360 whwmd4300m000 and filter the finished item at the receiving warehouse from step 1.5 finished item on-hand after; on-hand has increased by the production quantity over step 0.6. On the No path this only holds once Warehousing has finished the inbound procedure

Troubleshooting

Phase
Symptom
What to check or do
0No qualified item/BOM/routing combination is availableStop. This guide does not create or repair master data; request a qualified training case
0Component has no suitable warehouse stockChoose another qualified case or replenish it before creating an order intended for later execution
1The item or revision is rejectedStop and have the master-data owner verify the existing item and revision; do not change setup from this guide
1The order does not save at CreatedRecord the message and visible fields; do not substitute guessed values
2BOM or routing is blank or unexpectedCheck the qualified dates/revisions and record the mismatch
2Validation reports a multilevel BOM loopStop. Do not improvise a replacement component or revision; the supported correction route is not yet documented
2Expected operation or component is absentLeave the order at Created and return it to the master-data owner for diagnosis
3The order does not reach ReleasedRecord the message; the release options this guide does not exercise (shortages, quality, printing) may be blocking it — check them against Production Order Parameters tisfc0100s000 before assuming a fault
4The material line stays blocked / To Issue by Warehouse never appearsRun Initiate Inventory Issue tisfc0207m000 manually; if still blocked, stop and record what was observed
4Generate/Release Outbound Advice are missing or already actionedDo not assume a fault. Direct Process Warehouse Order Line may be automatic for this material — confirm in Activities by Warehousing Order whinh2104m000 before troubleshooting further
5Report Orders Completed does not open after the last operationStop and record the operation's status and any message; this dialog's trigger condition is not documented
5Quantity Delivered stays at 0 or finished-item on-hand does not increaseThe production receipt warehousing order may need manual processing, like phase 4's issue order. Check Warehousing Orders whinh2100m000 for an open receipt order before assuming an error
